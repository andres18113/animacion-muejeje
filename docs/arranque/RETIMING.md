## Calculation and constraints

The speech interval is measured from the first non-whitespace character to the end of the last character that is neither punctuation nor whitespace, reading the current alignments from disk. Internal pauses within each sentence are not measured acoustically. The global complement includes gaps between cues, tails, and entrances across cuts, without counting them twice.

The integer 3 MHz clock represents both microseconds and exact frames (100,000 ticks/frame at 30 FPS). For each original silence d, the uniformly quantized reduction is r(d,c) = max(0, ceil((d−c)/100000)) frames. Bisection finds the smallest cap c such that 9900−Σr(d,c) ≥ 300×30. The fixture retains the original 330 s layout and the ticks regenerated by the host with the current audio; it is not modified in this adjustment.

Recalculated result: c = 10,940,000 ticks, total = 9000 frames. With c−1 tick, **8997 frames** remain, below RNF-10. The bound without additional constraints is feasible under all audio and reading constraints, and is therefore also optimal with them. The measured maximum is exactly 10,940,000 ticks, equal to C; there are no exceptions.

Each original silence exceeding C loses ceil((d−C)/100000) frames; the others retain their duration. Quantization can leave the result less than one frame below C. Reductions are assigned to the preceding scene's tail or, within S05, shift its later cues and ending. Some pauses regain frames compared with the previous retime because C increased and the calculation starts again from the original layout; none increases compared with that original.

The following are retained: ≥100 ms audio reserve per cue, ≥8 frames between speakers, H02's 10-frame entry/exit, ≥1 s reading time for technical beats, and ≥0.8 s between the last speech and each scene's end. No tween exceeds the last visible frame. The host's tecladoInicio ≥ videoFin+6 correction in S06 is retained.

It retains exact equality for all quantized silences, global partition, reserves, H02 margins, reading, and absence of truncated tweens.
