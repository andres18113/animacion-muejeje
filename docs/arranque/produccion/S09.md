## Contract

One Mebre cue with the verbatim §8 text (frames 20–840, 120.7 wpm). Input: actual state `S08:749` (512 B at `0x7C00–0x7DFF`, BIOS still executing). §6.9 values:
- Code `0x000–0x1BD` (446 B).
- Partitions `0x1BE–0x1FD` (4 × 16 = 64 B).
- Signature `0x1FE–0x1FF` = `55 AA` (01010101 / 10101010; little-endian word `0xAA55`).

Output: the CPU executes GRUB Stage 1 from `0x7C00`. Control goes to the code, not the table. No VBR (§10.2). No claim that the signature certifies a valid OS. Mebre is the sector and its contents, not a device (§7.4).
