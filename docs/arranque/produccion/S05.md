## Actual codes and failure semantics

Primary source: Intel SE440BX-2 TPS 721632-001, September 1998, BIOS 4S4EB2X0.86A, table 66, pp. 83–84. Local PDF/extraction/captures in `out/produccion/S05/fuentes/`. Worker visually inspected `tabla66-83.png` and `tabla66-84.png` and read `codigos-post-verificados.md`.

- **20h**: DRAM refresh test;28h: DRAM sizing. These are checkpoints, not unconditional errors or proof of successful completion. Shown only after configuring 82443BX.
- **2Ch**: ADDRESS-line failure, never data bit. Alternative specimen shows two abstract addressesA/B reaching the same cell, without inventing which line failed or concrete addresses. Code 2Ch appears at 42px in that case; POST explicitly halted. Main case retains 28h and “Caso principal:continúa”; it does not halt or magically repair itself.

Educational order compatible with §4 operations; not presented as universal chronology for all BIOS. Example 0x1000/10100101/0xA5/165 comes from §6.5, labeled **Ejemplo didáctico RAM**; it is not SPD content or exact BIOS algorithm.
